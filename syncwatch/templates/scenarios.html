Fix the bad CRM records

Fills in the missing amount, currency and billing email through CRM PATCH calls. The next run should then sync those deals and clear the open issues.

Suggested walkthrough

  1. Run a sync with everything off. It comes back partial: about 60 invoices are created and 4 records fail with data-quality errors.
  2. Run it again. Already-invoiced deals are skipped, no duplicates are created, and the same 4 records fail again. The “runs failed” count on the Overview page goes up.
  3. Turn on crm_throttling and token_expiry, then run. The run still finishes because it backs off and refreshes its token. Each retry is logged as a warning.
  4. Turn on finance_outage. After 3 failures in a row the circuit breaker stops the run, which is marked failed and sends an alert.
  5. Turn on schema_drift. The run stops on the first record with one clear SCHEMA_CHANGE error instead of 60 confusing ones.
  6. Switch everything off, press Repair data, then run. You get succeeded, and Reconciliation shows Balanced.
  7. Press Edit a deal. Reconciliation now catches a 250.00 mismatch.
