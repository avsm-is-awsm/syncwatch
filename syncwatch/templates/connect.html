REST API

Full OpenAPI spec at /openapi.json, with an interactive version at /docs.

curl -X POST {{ base }}/api/sync/run
curl {{ base }}/api/health/summary

Power Automate

You can call these endpoints from a cloud flow with the HTTP action. One example is a scheduled flow that runs POST /api/sync/run and posts to Teams when status isn’t succeeded. To use them as a custom connector, convert /openapi.json to OpenAPI 2.0 first, because custom connectors only import Swagger 2.0.

Alerts

Set ALERT_WEBHOOK_URL to a Teams Workflows or Slack incoming webhook. Any run that isn’t a full success then posts a summary there: which categories failed, who owns the fix, and a link to the run.
